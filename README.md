## Requisitos
- JDK compatible con la configuración del proyecto.
- IntelliJ IDEA.
- Conexión a internet para descargar las dependencias de Maven, si es necesario.

## Instrucciones de ejecución
1. Clonar o descargar el repositorio.
2. Abrir en IntelliJ IDEA la carpeta del proyecto que contiene el archivo `pom.xml`.
3. Esperar a que Maven cargue las dependencias.
4. Ejecutar la clase principal co.edu.univalle.poe.mvc.BlackJackApplication.
5. Cuando se abra la ventana del juego, seguir las instrucciones de la interfaz para jugar.

También se puede ejecutar desde una terminal en la raíz del proyecto mediante: mvn clean javafx:run
